# Double Machine Learning: 401(k) Eligibility and Household Wealth

A replication project examining the effect of 401(k) eligibility on household wealth using Double Machine Learning (DML).

## Objectives

- Replicate the DoubleML 401(k) example
- Compare OLS and DML estimates
- Implement cross-fitting manually in Python
- Explore an optional instrumental variables extension

## Tools

Python, scikit-learn, DoubleML, pandas, WSL

## References

Chernozhukov et al. (2018), Double/Debiased Machine Learning for Treatment and Structural Parameters.
